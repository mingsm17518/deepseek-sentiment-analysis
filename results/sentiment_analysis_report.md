# 情感分析结果报告

## 一、数据概况

本次情感分析涵盖三大社交媒体平台，包括抖音、微博和小红书，共计处理评论数据 **3363 条**。

| 平台 | 数据来源 | 评论总数 |
|------|----------|----------|
| 抖音 | douyin_cleaned.xlsx | 1021 |
| 微博 | weibo_comments_cleaned.xlsx | 717 |
| 小红书 | xiaohongshu_comments_cleaned.xlsx | 1625 |

## 四、结论与建议

### 4.1 主要发现

1. **整体态度积极**：三大平台的正向评论占比均超过 48%，其中小红书正向评论占比最高（60.8%）

2. **负面评论较少**：各平台负面评论占比均低于 18%，负/正比例均在 0.35 以下

3. **平台差异明显**：
   - 小红书用户态度最为积极，正面占比 60.8%，负/正比例仅 0.10
   - 微博用户态度次之，正面占比 56.2%
   - 抖音负面占比相对较高（9.9%），中性评论占比也较高（41.3%）

4. **抖音中性评论较多**：抖音平台中性评论占比达 41.3%，表明部分评论与话题关联性不强

### 4.2 发展建议

1. **依托短视频推广**：抖音正面评论表现良好，应继续发挥短视频传播优势

2. **注重内容质量**：微博负面评论占比较高（15.2%），需关注内容质量提升

3. **维持小红书优势**：小红书用户认可度最高，建议保持现有运营策略

4. **优化负面评论**：针对负面评论集中的问题进行改进，提升用户满意度
